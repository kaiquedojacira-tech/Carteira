# Minha carteira

App de controle financeiro e investimentos em um único arquivo HTML (`index.html`).

- Painel com regra 50/30/20 e ciclo mensal
- Despesas, receitas e gastos recorrentes
- Investimentos: aportes, rendimento da renda fixa pelo CDI e saldo real do CDB dia a dia
- Gráfico de evolução, com modo tela cheia na horizontal

## Como usar

Abra o `index.html` no navegador. Para publicar de graça, ative o GitHub Pages
em Settings > Pages, escolhendo a branch `main` e a pasta raiz.

Os dados ficam salvos no próprio aparelho.
